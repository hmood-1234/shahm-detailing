
# شهم للتلميع

نظام إدارة محل تلميع السيارات.

## أهداف النظام
- تسجيل العملاء والسيارات.
- إصدار الفواتير.
- إدارة الخدمات والأسعار.
- متابعة المخزون والمصروفات.
- حساب الأرباح.
- إدارة الموظفين والصلاحيات.

## العملة
الريال العماني (OMR).

## المستخدمون
- المدير: صلاحيات كاملة.
- الموظف: تسجيل السيارات وإصدار الفواتير فقط.
